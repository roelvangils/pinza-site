Raindrop.io

Raindrop.io is a bookmark manager. Connected, the HUD grows a Bookmark button: copy a link, click one button, and it's filed — with a collection and tags — without opening Raindrop at all.

Setup

  1. Open Settings → Integrations → Raindrop.io.
  2. Click Sign in with Raindrop.io and approve in the browser.

Using it

  1. Copy a link with your Copy shortcut.
  2. Hover the HUD and click Bookmark (or press ⌘D).
  3. Pick a collection, add tags if you like, and save.

Details worth knowing:

  • If the link is already in your Raindrop, the button reads Bookmarked with a checkmark — no duplicates.
  • If you copied a text highlight, the highlight travels into the bookmark.

If you'd rather not see the button

The Bookmark button appears on every copied link once you're signed in. Turn it off with Settings → Integrations → Offer "Save to Raindrop" after copying a link — bookmarking then stays available from the pin's actions menu.
