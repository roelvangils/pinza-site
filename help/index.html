Pinza Help

Pinza lives in your Mac's menu bar. Press one keyboard shortcut and it copies the most useful reference from whatever you're looking at: the URL of your browser tab, the path of the file selected in Finder, a deep-link back to a mail message. Paste it anywhere.

These pages explain everything the app can do. If you're new, start with the tutorial.

  • Getting started Install Pinza, grant the two permissions, and copy your first link.
  • Example use cases Ten everyday things Pinza is good at, step by step.
  • The HUD The small card that appears after you copy, and everything it can do.
  • The Launcher A Spotlight-style window for searching and managing your pins.
  • Configuring Actions Customize the Copy as… menu and write your own copy formats.
  • Integrations Connect Notion, Google Drive, Raindrop.io, Mistral OCR, and more.
  • Settings reference Every pane and every option, with defaults.
  • Supported apps What Pinza copies from each of the 40+ apps it understands.
  • Power users The config file, pinza:// links, and other plumbing.
  • Troubleshooting Permissions, shortcut conflicts, and app-specific quirks.
  • FAQ Licensing, pricing, privacy, and other common questions.
  • What's coming Features that are planned but not shipped yet.
